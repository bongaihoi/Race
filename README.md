# Race

A mobile-friendly top-down racing game: steer left and right to avoid road hazards and beat four AI rivals.

## Play

Open `index.html` in a browser. On a phone, hold the on-screen **TRÁI / PHẢI** buttons to steer. On a computer, use **← / →** or **A / D**.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once Pages finishes publishing, open the URL shown on that settings page.
